Teach first — words Lab 02 did not need yet

TermPlain English
dbt source A declaration that “this Snowflake table already exists outside dbt” (our LANDING.TXN_EVENTS). Models use {{ source(...) }} so renames are tracked.
Contract A promise about column names + types on a published model. If a PR renames order_total, dbt fails the build instead of silently blanking Alex’s tile.
Slim CI In pull requests, only build models that changed (and downstream), using a saved prod manifest — not the entire Meridian graph every time.
state:modified+ Selector: “models that differ from the saved state, plus everything that depends on them.”
--defer For parents you didn’t rebuild in CI, read the already-built prod relation instead of rebuilding the world.

Sources boundary — LANDING.TXN_EVENTS

Without a source entry, dbt still can query the table via raw SQL — but you lose lineage and freshness hooks. Meridian declares the dock explicitly.

YAML · dbt_project/models/staging/_sources.yml
version: 2

sources:
  - name: landing
    database: MERIDIAN_BANK
    schema: LANDING
    tables:
      - name: txn_events
        description: "Meridian Bank txn events for incremental merge demo"

Contract on the published mart

YAML · contract example
version: 2

models:
  - name: fct_orders_incremental
    config:
      contract:
        enforced: true
    columns:
      - name: order_id
        data_type: number
        tests: [unique, not_null]
      - name: customer_id
        data_type: number
      - name: status
        data_type: varchar
      - name: order_total
        data_type: number
      - name: updated_at
        data_type: timestamp_ntz
        tests: [not_null]
