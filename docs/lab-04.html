Data Vault — talk-track only (not today’s build)

If Marcus asks “what about Data Vault?”

Data Vault is a modeling style for enterprise warehouses: hubs (business keys), links (relationships), satellites (attributes that change over time). Meridian’s lab stays on a simple three-layer medallion so the story is obvious in one whiteboard.

Why aggregate here?

Alex wants lifetime value and txn counts — that’s a business question, not a raw feed. Gold reads silver only, never BRONZE_LANDING directly.

SQL · GOLD_MART.GOLD_CLIENT_SUMMARY
CREATE OR REPLACE TABLE GOLD_MART.GOLD_CLIENT_SUMMARY AS
SELECT CLIENT_ID, COUNT(*) AS TXN_COUNT, SUM(AMOUNT) AS LIFETIME_VALUE, MAX(UPDATED_AT) AS LAST_UPDATE
FROM SILVER_CURATED.SILVER_TXNS
GROUP BY CLIENT_ID;

Interviewer presses further — say these out loud

Basics got you into the room. Cover each answer before you open it. If you blank here, an Architect + dbt interviewer will know.

Q1. Why teach CTAS medallion before dbt if prod uses dbt?

Say: Medallion is the floor plan; dbt is how we furnish it. If I only show folders, people think staging/marts are Snowflake schemas. I name BRONZE_LANDING / SILVER_CURATED / GOLD_MART first, then map dbt models onto those schemas.

Q2. Do dbt folders staging/marts become Snowflake schemas?

Say: No — folders are repo layout. Our generate_schema_name + dbt_project.yml send silver models to SILVER_CURATED and gold marts to GOLD_MART. Lab 02’s incremental fact overrides to SILVER_CURATED because it’s a silver grain, not a board mart.

Q3. What belongs in BRONZE_LANDING that must never be Alex’s default path?

Say: As-landed PII and raw events — CLIENTS vault, unvalidated TXN_EVENTS. Alex reads SILVER_CURATED windows and GOLD_MART tiles. Bronze is Jordan’s dock; dbt sources it, it doesn’t remodel PII into Looker.

Q4. When would you skip Gold and let Finance query Silver?

Say: Early product, few consumers, metrics still changing — Gold is ceremony. Once Marcus’s KPIs stabilize, GOLD_MART freezes grain. Don’t invent Gold to “complete medallion.”

Q5. Who orchestrates dbt run for silver→gold nightly — dbt, Tasks, or Airflow?

Say: dbt defines the graph; something must trigger it. Snowflake Tasks fit Snowflake-native CDC; Airflow fits multi-system DAGs (files land → dbt → notify). Lab 15 covers that fork — I don’t pretend dbt schedule alone is the enterprise bus.

Outcome: agreed lineage; engineers land raw; dbt builds silver/gold; analysts consume gold.”
